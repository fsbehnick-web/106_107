# Инструкция по запуску и управлению ботом

## 🚀 Быстрый запуск
Чтобы запустить бота вручную, просто дважды кликни по файлу `start_bot.bat`.

## ⚙️ Автозапуск (Windows Task Scheduler)
Чтобы бот работал 24/7 в фоне:
1. Нажми `Win + R`, введи `taskschd.msc` и нажми Enter.
2. Справа выбери **"Создать простую задачу" (Create Basic Task)**.
3. Имя: `ClaudeTelegramBot`.
4. Триггер: **"При входе в Windows" (When I log on)**.
5. Действие: **"Запуск программы" (Start a program)**.
6. Программа: `C:\Users\4\Desktop\cc\telegram_bot\start_bot.bat`.
7. В поле "Рабочая папка" (Start in) укажи: `C:\Users\4\Desktop\cc\telegram_bot`.
8. Нажми "Готово". Теперь бот будет запускаться сам при каждом входе в систему.

## 📋 Мониторинг и логи
Весь вывод бота (ошибки, запросы) записывается в файл:
`C:\Users\4\Desktop\cc\telegram_bot\bot_output.log`

## 🛑 Как остановить бота
1. Открой **Диспетчер задач** (`Ctrl + Shift + Esc`).
2. Найди процесс `python.exe` (вкладка "Подробности").
3. Нажми "Снять задачу".

## 🔄 Как обновить бота
Если ты внес изменения в `bot.py`, просто перезапусти его через `start_bot.bat` или через Планировщик задач.
